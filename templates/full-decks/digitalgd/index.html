Overview

统一共享平台是什么？

统一平台

统一的数据共享服务平台，实现目录编目、供需对接、授权共享与运行监测。

多级联动

覆盖多级组织单元，打破数据孤岛，推动跨层级、跨部门数据流通。

应用驱动

以业务需求为导向，支撑政策自动兑现、快速审批等公共服务创新。

安全可控

建立数据分类分级、脱敏标准与责任追溯机制，确保共享与安全并重。

2.2 业务流程优化

数据共享更快捷、更高效

1

编目挂接

数据提供方按标准编目，挂接至统一目录，一次编目、多级复用。

→
2

需求申请

数据使用方在线提交共享申请，权限下放至业务处室，减少层层审批。

→
3

授权共享

平台自动匹配数据资源，完成授权与接口调用，全程可追溯。

业务流程
三步流程：编目 → 申请 → 共享，强调权限下放带来的效率提升。

2.3 多种数据共享形式

满足不同场景的数据流通需求

API 接口

实时查询调用

通过标准化 API 接口，支撑业务系统实时获取数据，适用于高频查询场景。

批量交换

定时推送同步

按约定周期将数据推送至交换节点，适用于大批量、低频更新场景。

隐私计算

数据可用不可见

基于隐私计算技术实现「数据不出域、价值可流通」，适用于敏感数据协作。

2.4 保障机制

制度 + 标准 + 安全 三位一体

✓
组织保障

省级专项工作组统筹，明确数据提供方与使用方责任，建立考核评估机制。

✓
标准规范

制定数据编目、质量、脱敏等标准规范，编目挂接时提供国标、地标参考。

✓
项目审查

项目验收前进行数据符合性审查，确保新建系统数据应汇尽汇、应享尽享。

✓
数据安全

落实公共数据脱敏标准，分类分级管理，全程留痕可追溯。

保障机制
四条保障机制，覆盖组织、标准、项目和安全四个维度。
