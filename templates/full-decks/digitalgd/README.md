# digitalgd · 政务数据平台汇报

12-slide public-data sharing deck template with DigitalGD gov-tech styling.
Content uses generic placeholders — replace with your own project names and metrics.

**Slides:** cover → TOC (sidebar nav) → section ×2 → timeline → overview → KPIs → process flow → share modes → safeguards → use cases → thanks.

**Visual traits:** gov-tech blue (`#2D32F2`), Microsoft YaHei, left brand rail, cover with abstract tech-grid background.

**Uses theme:** `assets/themes/digitalgd.css` (T-key switch to `corporate-clean` / `arctic-cool`).

**Use when:** 公共数据共享汇报、平台运营复盘、多级数据治理经验分享。

**Path:** `templates/full-decks/digitalgd/index.html`

```bash
cp -r templates/full-decks/digitalgd examples/my-gov-talk
open examples/my-gov-talk/index.html
```
